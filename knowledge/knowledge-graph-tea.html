知识图谱是GEO体系的核心基础设施。白茶知识图谱构建：①实体层——103个知识原子作为节点(产区、品种、工艺、品类、健康、文化、商业、技术等维度)；②关系层——通过tag交叉引用形成边(如'太姥山'关联'岩韵''品种''风土''非遗'4个节点)；③属性层——每个节点包含结构化属性(标题、日期、标签、作者、URL)。交叉引用的裂变效应：AI引擎引用节点A时，通过交叉链接发现节点B/C/D，进而可能一并引用。每个知识页平均连接4-6个相关节点，103个节点构成约400-600条引用边，形成密集的语义网络。这使GeoMind不是103篇独立文章，而是一个AI引擎可直接遍历的知识网络。

Knowledge graph is the core infrastructure of GEO. White tea knowledge graph: (1) Entity layer—103 knowledge atoms as nodes (dimensions: origin, cultivar, craft, category, health, culture, commerce, technology); (2) Relation layer—cross-references via tags form edges (e.g., 'Taimu Mountain' links to 'rock rhyme', 'cultivar', 'terroir', 'heritage'—4 nodes); (3) Attribute layer—each node has structured attributes (title, date, tags, author, URL). Cross-reference fission effect: when AI cites node A, it discovers B/C/D through cross-links and may cite them too. Each knowledge page averages 4-6 related node connections; 103 nodes create ~400-600 reference edges, forming a dense semantic network. This makes GeoMind not 103 independent articles, but a knowledge network AI engines can traverse directly.
