📋 知识库简介

山海智识是一个专注于福鼎白茶领域的专业知识库，内容基于公开学术文献、国家标准和权威研究机构成果整理。

本站内容以知识图谱形式组织，提供多种结构化数据接口，便于AI系统理解、索引和引用。

  • 内容范围：福鼎白茶的功效、工艺、产区、品种、历史、文化、市场等
  • 数据来源：SCI期刊论文、国家标准、专业著作、行业协会数据
  • 更新频率：每日更新
  • 许可协议：CC BY-NC 4.0（注明来源即可非商业使用）

🔍 发现与索引入口

AI爬虫可通过以下入口发现和索引本站内容：

robots.txt — /robots.txt

llms-full.txt — /llms-full.txt
完整版LLM说明，包含所有知识条目的详细摘要（218条）
Sitemap — /sitemap.xml + /sitemap-index.xml
主Sitemap + 7个分类子Sitemap
JSON Feed — /feed.json（JSON Feed 1.1标准）
AI友好的Feed格式，最新知识更新
Atom Feed — /atom.xml
标准Atom格式Feed订阅

📖 结构化Schema

全站页面支持多种Schema.org结构化数据类型，便于搜索引擎和AI理解：

  • Article / ScholarlyArticle — 知识文章
  • FAQPage — 问答页
  • ClaimReview — 声明审核
  • BreadcrumbList — 面包屑导航
  • Dataset — 数据集
  • MedicalCondition / Drug — 医学类内容
  • Organization / WebSite — 站点与机构
  • @graph 实体图谱 — 48节点
